# Capstone-Project

TraffiX – AI-Powered Traffic Intersection Monitoring System
TraffiX is an AI-powered traffic monitoring system designed to detect, track, and analyze vehicles at road intersections using real-time CCTV camera footage.
The system uses computer vision and object tracking technologies to monitor traffic conditions and provide useful traffic information through a web-based dashboard.

How to Run-
   cd traffix
   npm install
   npm run dev
   Then open http://localhost:3000 in your browser.
   
We use these technologies for our TraffiX system.
