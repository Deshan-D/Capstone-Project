## About TraffiX

TraffiX is an AI-Powered Traffic Intersection Monitoring System designed to monitor traffic using CCTV camera feeds. The system uses Artificial Intelligence and Computer Vision to detect vehicles, and traffic violations, while providing real-time alerts and traffic analytics through a web-based dashboard.

## Project Purpose

The main purpose of TraffiX is to reduce the limitations of manual traffic monitoring by using AI to automatically analyse traffic conditions and identify potential traffic violations. The system aims to support traffic authorities in improving road safety, traffic management, and decision-making.
